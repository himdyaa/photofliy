PHOTOFLIY ADMIN

Portfolio content yahan se badlo — phir portfolio.json download karke repo me replace karo. Ye page main site se link nahi hai, sirf jiske paas iska link hai wahi khol sakta hai.

Phone se update karne ke steps:
1. Neeche changes karo → Download portfolio.json dabao.
2. GitHub app / browser me repo photofliy kholo → portfolio.json → Edit (pencil) → purana text delete karke download ki gayi file ka text paste karo → Commit changes.
3. Site 1–2 minute me apne aap update ho jayegi. Nayi photo/video add karni ho to pehle assets folder me upload karo (repo me), phir uska naam Media list me likho (jaise assets/nayi-photo.jpg ya Drive link). Ek work me 2+ media hone par site par uska card apne aap scroll hoga (har 3 second me, loop me).
